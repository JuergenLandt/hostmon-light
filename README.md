# hostmon-light

**Docker Image: 6.71 MB**

Ein schlanker Host-Monitoring-Agent für Linux: ein Container, eine überschaubare Konfiguration und eine JSON-API für Host-Ressourcen. Keine Datenbank, keine Historie, keine integrierte Alarmierung.

A lightweight host-monitoring agent for Linux: one container, a straightforward configuration, and a JSON API for host resources. No database, no history, no built-in alerting.
